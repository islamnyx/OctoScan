OctoSec Labs will run automated, black-box security checks against the listed target(s) only, using the OctoScan platform. The scan includes:

  • Network and open-port scanning of the listed target
  • TLS/SSL configuration review
  • HTTP security header and cookie configuration review
  • Automated web application scanning for common vulnerability classes (e.g. XSS, SQL injection, CSRF, CORS misconfiguration), using standard scanner payloads only
